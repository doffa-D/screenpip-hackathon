# Melon: from memory to action

## The pitch

“We repeat small tasks across spreadsheets, documents, email, and messaging apps. Melon turns work you have already done into reusable workflows. Find a past task, review the steps, update the details, and let Melon help you do it again.”

## The full pipeline

**Work normally → Capture history → Find a task → Reconstruct steps → Review and save → Run → Verify and report**

1. **Capture:** Screenpipe records activity locally. Melon’s Record page marks the start and end of a task inside that history; it does not start or stop Screenpipe itself.
2. **Understand:** Background discovery identifies task occurrences and repeated patterns. Memories lets you browse them; Chat helps you find relevant past work.
3. **Reconstruct:** The AI retrieves evidence for a selected occurrence and extracts its goal, steps, historical values, and missing information. Source references connect the plan to the observed activity.
4. **Review and save:** You check the plan, edit its steps or values, fill in missing details, and save it in Workflows. A saved workflow is a reusable task definition, independent of the temporary search results.
5. **Run:** You choose a workflow and provide the details for this run. The execution agent inspects the current app interface and performs the steps using desktop tools. It adapts to the live interface rather than replaying recorded mouse coordinates. Approval controls let you review proposed actions.
6. **Verify:** Melon checks the live result and records progress, errors, and the outcome. You can stop a run and review its report.

## How one workflow creates value

**Example: prepare a spreadsheet report and share it on WhatsApp.**

- **First time:** Do the task normally and mark its recording interval, or find the past occurrence in Memories.
- **Turn it into a workflow:** Review the recovered steps: select the sheet, prepare the report, export the PDF, and share it. Check the document, recipient, and other recovered values.
- **Next time:** Open the saved workflow, update the relevant details, review, and run it again.
- **Benefit:** You reuse the process without having to explain every step from scratch.

## Three ways to reuse it

| Mode | What it does |
| --- | --- |
| Run now | Repeat a reviewed workflow when you need it. |
| Schedule | Run a saved workflow at a chosen time or recurring interval. |
| Night shift | Suggest missed follow-up tasks and prepare approved workflows overnight, within a scope you choose. By default, it stops before final actions such as sending. |

## A simple demo story

“Here is something I already did in Memories. Melon recovers the steps and the evidence. I review them and save a workflow. Now I can reuse it with updated details, schedule it, or approve an overnight preparation. Afterward, I can see what happened.”

## What makes it different

**Memory gives the context. A workflow makes that context reusable. Live execution turns it into action.**

For an honest pitch: this is a local prototype, and execution depends on supported app controls and available evidence. Overnight work requires the app running and an unlocked PC. Demo-labelled Night shift examples are illustrative and cannot execute. History is stored locally, while retrieved context is sent to the configured AI provider for reasoning.
