# xa11y Test Script Implementation Plan

> Execute inline in this session.

**Goal:** Inspect current desktop accessibility and test a real text edit with timing.

**Architecture:** Keep xa11y in an optional standalone script. Default to listing apps; support an explicit app snapshot and a new Notepad fixture demo. Save timings and outcomes as JSON in ignored artifacts.

**Tech Stack:** Python 3.12, xa11y 0.15.2, Windows UI Automation.

**Spec:** User request to write a script to test and use https://github.com/xa11y/xa11y.

## Constraints

No backend execution endpoint or automatic replay of historical tasks. Demo edits only a uniquely named document created by the script. Retain the test window for inspection.
