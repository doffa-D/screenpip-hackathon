# Recall Desktop Implementation Plan

> **For agentic workers:** Execute inline in this session. User has authorized implementation.

**Goal:** Launch the existing real-data Recall product as a native Windows application.

**Architecture:** A pywebview Edge WebView2 window hosts the built React interface. The desktop process owns a single FastAPI server thread on a separate loopback port, reuses the existing environment and data, and redirects global navigation shortcuts to its own window. Closing shuts down jobs and desktop workers through the existing lifespan.

**Tech Stack:** Python, pywebview 6, WebView2, existing FastAPI and React.

**Spec:** User request: convert the project to a desktop app instead of a web app.

## Global Constraints
- Preserve real Screenpipe/Zavora integrations, approvals, evidence and timestamp-only recording.
- Preserve existing .env and .data; never bundle credentials.
- Do not take ownership of or terminate an existing web server.
- Desktop launch needs no browser tab; backend development remains available separately.
