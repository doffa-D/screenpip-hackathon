# Recall Chat Implementation Plan

> **For agentic workers:** Execute inline in this session. No delegation is authorized.

**Goal:** Control Recall's real features through a conversational assistant.
**Architecture:** A bounded Azure/OpenAI tool loop discovers allowed operations from the app's OpenAPI schema. Internal ASGI calls reuse validation and services. Writes become immutable, single-use confirmation cards; execution approval stays in Runs. Server-owned conversation state prevents forged tool history.
**Tech Stack:** FastAPI, existing OpenAI SDK, httpx ASGITransport, React.
**Spec:** User request: chat controls old-task discovery, workflow runs, recording and the full existing feature set.

## Global Constraints
- Real APIs and data only; no arbitrary HTTP, shell or desktop tool exposed.
- No automatic task selection. Task reconstruction and all writes require an explicit action-card selection.
- Never expose provider credentials or let model approve desktop actions. Provider changes remain in Settings.
- Recording bookmarks time only. Existing execution approvals remain mandatory.
